# Tutorial: Intro to HPC

This tutorial introduces the basic workflow for using Yale's High Performance Computing (HPC) resources.

## Topics covered:

- YCRC resources and HPC basics

- Accessing the cluster with Open OnDemand and the terminal

- Managing files and navigating the Linux shell

- YCRC storage and data transfer

- Running interactive and batch jobs with Slurm

- Monitoring jobs and resource usage
