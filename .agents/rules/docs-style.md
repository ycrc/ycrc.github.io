# YCRC Style Guidelines for Documentation

When editing or creating documentation files in `docs/`:

1. Always preserve the YAML metadata or H1 title at the top of the file.
2. Verify that any new internal link does NOT end in `.md`.
3. Verify that code blocks specify a language syntax highlight tag (e.g. `bash`, `yaml`, `python`).
4. Ensure commands in code blocks do not start with `$` or `#`.
5. If adding a new page, remind or automatically update `mkdocs.yml` under `nav:`.
